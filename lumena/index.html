Guía de Instalación para Principiantes (Paso a Paso)

PASO 1

Instalar la extensión Tampermonkey

Para que el navegador entienda y ejecute scripts de juegos, necesitas instalar un gestor gratuito llamado Tampermonkey.

  • Entra a la tienda oficial de extensiones de tu navegador (Chrome Web Store, Microsoft Edge Add-ons o Firefox Add-ons).
  • Busca Tampermonkey y haz clic en Añadir / Instalar.
  • Asegúrate de fijar el icono de la extensión en la esquina superior derecha de tu navegador para tenerlo a la mano.
PASO 2

Descargar el archivo del Bot

Haz clic en el botón superior que dice 📥 Descargar Script. El archivo con terminación .user.js se guardará automáticamente en tu carpeta de descargas habitual.

PASO 3

Activar el script (Método Infalible)

Para evitar bloqueos o errores automáticos del navegador, realizaremos una instalación manual sumamente sencilla:

  • Haz clic sobre el icono de Tampermonkey en la barra superior de tu navegador y selecciona "Tablero" (Dashboard).
  • Abre tu carpeta de Descargas de la computadora y arrastra el archivo lumena-bot.user.js directamente hacia la ventana abierta de Tampermonkey.
  • Se abrirá una pantalla con el código del script. Haz clic en el botón verde de Instalar.
  • ¡Listo! Entra al juego y el bot se ejecutará de forma automática.
